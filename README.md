# Backend - Experiments

## Motivation/Purpose

The core purpose of this repository is to enhance my FastAPI/backend proficiency, while building projects.
The idea is not to learn how to build toy projects, instead, master the fundamentals and best practices, which make FastAPI 'fast, mordern and modular', by design.

Concepts from this experiment repo will be fully adopted by projects like 'Ageless-Companion' & 'Shabd-Shuchi'

## Directory Structure & Schema of the Respository
There are various sub directories & each sub directory acts as a standalone projects, having it's very own scope, requirements, practical application of concepts and engineering methodology.
